Task 1. Form with HTML5 validation

The browser checks the fields itself when you press Send. No JavaScript is used for the checking.

All fields are valid, the form was accepted.

What I tested

  • Empty form: browser stops and says to fill the first field.
  • Email without @ (for example "duman.mail.com"): browser says the email is wrong.
  • Name with 1 letter: browser says it is too short (minlength).
  • Phone "12345": browser shows the title text because the pattern does not match.
  • Message longer than 300 characters: not possible to type, maxlength stops it.
